Gain and contrast
  • Darker / brighter change the analog input gain. Auto Gain chases white, then turns off when you set gain by hand.
  • Contrast stretches black to white on the scaled picture. A profile stores it with the picture.

  • Keeps the game frame and the output frame the same length, so a tear line does not crawl through the picture.
  • VTotal + VSST also shifts the vertical sync. VTotal only changes the frame length. If the screen goes blank or jumps, use the other one.

Filters
  • Scanlines only work with 240p sources, or 480i with Bob deinterlacing.
  • Pandora 640×480 is progressive 31 kHz, about 525 lines. The line doubler stays off, so this overlay does not draw. Use 384×224 for GBS scanlines.
  • Line Filter eliminates blocky-pixel artifacts when upscaling beyond 480p, and is recommended.
  • Peaking increases contrast around horizontal brightness steps, and is recommended.
  • Step Response increases the sharpness of horizontal color steps, and is recommended.

Low Res: Use Upscaling
  • Low Resolution VGA input: Pass-through or Upscale
  • Low resolution sources can be either passed on directly or get upscaled.
  • Upscaling may have some border / scaling issues, but is more compatible with displays.
  • Also, refresh rates other than 60Hz are not well supported yet.
  • "Low resolution" is currently set at below or equal to 640x480 (525 active lines).
